# Where the installed prediction models are

Where the installed prediction models are

## Usage

``` r
mlmorph_models_dir(version = NULL)
```

## Arguments

- version:

  A bundle version; `NULL`: the one this version of intraitR names if
  installed, otherwise the most recent installed.

## Value

The folder (usable as `mlmorph_dir`), or `NULL` when none is installed.
