# The prediction models installed on this machine

The prediction models installed on this machine

## Usage

``` r
mlmorph_models_info()
```

## Value

A data.frame: `version`, `folder`, `size_mb`, `intact` (every file
matches the manifest), `this_package` (the version this intraitR names).
