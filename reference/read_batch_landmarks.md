# Read the output of [`batch_landmarks()`](https://funtraits.github.io/intraitR/reference/batch_landmarks.md)

Read the output of
[`batch_landmarks()`](https://funtraits.github.io/intraitR/reference/batch_landmarks.md)

## Usage

``` r
read_batch_landmarks(out_dir)
```

## Arguments

- out_dir:

  Output folder of
  [`batch_landmarks()`](https://funtraits.github.io/intraitR/reference/batch_landmarks.md).

## Value

A list: `summary`, `landmarks` (long) and `out_dir`; `flags` is `""` for
a photograph without any flag.
